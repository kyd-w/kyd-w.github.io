# 自我进化智能体跟踪快照 · 2026-11-14

> 例行扫描（上次快照 11-08）。🚨 机制层第三深度（harness 自我改写）本月完成"学术定名→工程化→产品化→平台原生"四级跳——本课题建档以来最清晰的一次范式收敛信号。

## 🚨 变化：harness 自我改写（第三深度）标准化收敛

四级链条（按时间）：

1. **学术定名**：[Self-Harness: Harnesses That Improve Themselves](https://arxiv.org/abs/2606.09498)（arXiv 2606.09498，H. Zhang et al.，被引 111+）——agent 改写自己的 harness 的三段循环：**失败挖掘 → harness 提案 → 回归测试**，不依赖人类工程师或更强外部模型。"Self-Harness"成为该方向的正式范式名
2. **主流工程化**：[Lilian Weng《Harness Engineering for Self-Improvement》](https://lilianweng.github.io/posts/2026-07-04-harness)（07-04）——harness 工程成体系方法论（并行子代理 spawn / 后台任务监控 / 自我改进循环的工程要点）
3. **产品化（待验证）**：DSH「创造模式」（11-02，中文源）——用户对话让 Agent 给 DSH 自己定制界面/按钮/插件（自制"节奏工作台"鼓机插件演示）——harness 自我改写首次以消费级功能形态出现
4. **平台原生**：Claude Managed Agents [「Dreaming」](https://platform.claude.com/docs/en/managed-agents/dreams)（闲时复盘会话、重组记忆、持续学习；约 05-09 研究预览上线）+「Outcomes」（结果自验证）——**学习循环成平台一等公民**；第三方口径 Harvey 借此获 6 倍任务完成度提升（转引待验证）

**判断**：机制层三深度（技能沉淀→模式工程化→harness 自我改写）的第三深度，从 11-08 口径的"研究散点"跃迁为**有名字、有方法论、有产品、有平台**。下次跟踪起，"Self-Harness"作为第三深度的标准检索词。

## 载体层：3 代厂商亲自常驻化 + 2 代托管商业化

1. **dsh-superagent-prototype**（10-31，DeepSeek 官方，MIT，[repo](https://github.com/deepseek-ai/dsh-superagent-prototype)）：
   - 常驻在线 coding agent：监听 GitHub（issue/PR/review）+ 可选飞书，事件驱动自动出 PR，支持并行推进多项工作
   - 设计原则"**会主动干活，更懂何时闭嘴**"（介入分寸规则化）——主动性与边界的工程化提法首次见诸官方原型
   - 定位：DSH 之上的插件/研究原型（非第 4 代新载体），但**编排 OS 厂商亲自下场常驻智能体** = 第 3 代载体向常驻特化演进的官方信号；中文媒体解读"剑指 Claude Code"（腾讯新闻，转引）
2. **Hermes Agent**（2 代）：v0.23.0 "Hearth"（11-05，~850 issues 关闭）+ v0.23.1（11-10）——迭代节奏稳定（月度双版）；**Hermes Cloud**：付费 Nous Portal 计划各含一个常驻云 agent（自托管 → 官方托管商业化）；marketplace + 11 月黑客松（hermes-jobs 跨重启状态保持等条目）
3. 社区基建信号：awesome-dsh-plugin（每日自动抓取 + 人工复核 dsh-plugin 项目、剔除蹭标签）出现于 11-12——**插件生态大到需要 curation 基建**；dsh-web 插件全家桶（适配 V4.1）；百度千帆收录 dsh（10-29，国内平台化）

**换代判断**：无第 4 代信号。当前格局 = 3 代（DSH）向常驻化深化、2 代（Hermes）向托管商业化、平台派（dots / Managed Agents）吸收学习循环——三条路线正在"常驻 + 自我改进"处合流。
