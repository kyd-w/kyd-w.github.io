## 分仓详记

### 1. Astra → WSP：本日最重要发现，条目改口径

**溯源**：GitHub 检索 `astra+qwen`（24 条全无关）等功能检索均无独立项目；日志仓 README 铁证原文——"'Astra' in the post is OpenAI's `gpt-6-astra`"。时序吻合：仓库创建 10-29、博客宣发 ≈11-05，均在 W45 周报（11-08）前数天。

**机制**（博客 Exp8 + 全量日志公开）：GPT-6 Astra 在**无工具回路**（Codex CLI 全工具禁用、Python sandbox、最多 50 次 forward pass 反馈）中读 Qwen-0.8B 权重，定位"绕圈方向"，从第 15/19 层 MLP 各 64 输出列**直接减去该方向**——2×64×1024 = 131,072 权重，占 0.8B 参数的 **0.016%**。FAQ 明确：无梯度、无训练循环。结果：MATH-500 **7.9%→48.1%**、GSM8K 13.8%→67.1%、IFEval 21.0→62.3、截断率 93%→33%。

**粒度判定：既非 LoRA 亦非全量微调，第三类——无梯度稀疏直接权重编辑**。按课题二分法落在"权重直接编辑"一侧，机制上比全量微调更反共识。**11-08 立项的"反共识信号"判断成立并升级：权重侧自我进化通路已打开。**

两重降速（须随条目同行）：
1. **增益集中修"绕圈→截断"病而非注入能力**——Gemma 3 270M（不绕圈的模型）Astra 改不动；第三方复算指出增益伴随"完成作答数 22→124 暴增"，因果未隔离
2. **是大模型改小模型，非自进化载体**——GPT-6 Astra 改 Qwen-0.8B；小模型自改自己的复现**全部失败**。是前沿模型原生能力信号（WSP 概念），不是可迁移单品

**"失败转化为对话图变更"= 周报合成失真**：源博客 graph/conversation/memory/curriculum/scratchpad 关键词 0 次出现；实况仅为会话续跑 + 失败输出留在上下文驱动下一轮编辑。

**生态**（两周内）：100+ 复现/扩展（博客 11-12 更新口径）、衍生仓 ≥9、并行论文 iWSP（MSR/JHU，arXiv 2611.18114）、基准 IWIBench、HuggingFace live demo。

### 2. GenericAgent：干净实证，学习循环开源实证的最强样本

- **自述口径核对**：3.3K 行 ✅（shallow clone 实数：根目录 .py 剔模板/遗留后 3,400 行）；"6 倍 token 节省" ⚠️ 有真实评测但系头条口径——6.0× 为 Lifelong AgentBench（Sonnet 4.6）对 OpenClaw 最优组，跨基准 2.9–3.9×（报告脚注自认）；长程 5 任务对 Claude Code 2.85×
- **学习循环形态 = 运行时自改（代码级证据）**：agent 用自身 file_write/file_patch 把执行路径固化成 SOP 写入分层记忆（L0 元规则/L1 索引/L2 全局事实/L3 任务 SOP/L4 会话归档）；L1 带防写坏护栏（"no whole write!"）；反思由记忆系统触发而非用户；`memory/` 内 40+ SOP 即作者实例长出的技能树
- **常驻属性**：Reflect Mode 看门狗 + cron + Telegram/Discord/微信 IM 常驻前端 + service_manager——README 对标表直接与 OpenClaw/Claude Code 并列
- 保留项：README 自称"全仓库由 agent 自举完成，作者从未开终端"——**未证实**（commit 作者记录为人类名）；第三方独立复现未找到

### 3. EvoGroup：论文真实、代码未兑现、周报定性错误

- **空壳仓库**：1 commit（2026-11-02，与论文提交同日）、README 仅标题、无代码；论文脚注 1 声称代码在该仓，**截至 11-18 未兑现**
- **"群体"系周报误读**：论文的 Group Agent = 服务多用户群组的**单个** agent（开篇以 Slack 群聊数字员工为例），进化对象是该 agent 的 harness；"analysis agent / evolve agent" 是离线进化管线的分工组件，**不存在多 agent 互相改进**
- **harness 级名副其实但重心偏策略层**：修订面四接口 taxonomy（Representation/Operation/Intervention/Policy）是对"harness 能改什么"的形式化贡献；但实测分布 Policy 占 ~50%，工具实现改写是少数
- **与 Self-Harness（2606.09498）同族变体**：轨迹选择（confidence×outcome 双信号）→分析→修订→评测，两处实质差异：无回归测试门控（仅事后 Retention/Retention 93–95% 统计）、场景为群聊记忆垂直域。数字：held-out pass@1 71.07%→89.58%（DS-V4-Flash），超 Claude Code（85.83%）/ Codex（82.62%）——**不可独立核验（代码未兑现）**
- **旁证资格（限定用途）**：可作"harness 自我改写范式向垂直场景扩散、以 Claude Code/Codex 为直接对照"的深度 3 旁证；**不得**用作"多 agent 群体互进化"证据；永久标注"代码未兑现（截至 2026-11-18）"
