# 自我进化智能体跟踪快照 · 2026-11-02（建档）

> 建档快照：现状基线，无历史对比。数据快照日期：2026-11-02
> 来源：GitHub / Nous Research 文档 / CSDN（DeepSeek Harness v1.2 解析）/ arXiv / Reddit / Vellum·Composio 替代品清单

## 一、课题定位

自我进化智能体 = **载体层（常驻运行时）+ 机制层（进化能力）** 的组合方向。立项依据：

1. 2026 年 agent 领域最一致的未来叙事："从被动工具到从经验改进自己"
2. 载体层已被验证（OpenClaw 需求爆发）但单品生命周期极短（~8 个月）→ 价值在机制与范式
3. 进化路线收敛于"不动权重、进化外围"：技能库、记忆系统、harness 程序

## 二、载体层现状：三条路线分叉（换代第 2→3 代进行中）

### 路线 A：个人常驻助手（OpenClaw → Hermes Agent）

- **OpenClaw（第 1 代，已退热）**：60 天破 React 十年星标纪录（3 月，GitHub 史上最快），8 月 ~388k⭐；但 Reddit 社区现讨论"不会成为真产品"，各媒体替代品清单（Vellum/Composio/aimlapi，9 月）成为其退热标志。贡献：验证"本地常驻 + 既有消息渠道（Discord/iMessage/Slack/Teams/Telegram）"的需求形态
- **Hermes Agent / 爱马仕（第 2 代，现任头部）**：Nous Research，2026-02 开源，仓库持续活跃（11 月初仍有更新）。核心差异 = **唯一内置学习循环**：
  - 每完成 15 个任务自动复盘，分析成败、提取可复用技能
  - 两层记忆：常驻关键信息（MEMORY.md，每会话加载）+ FTS5 全文检索跨会话记忆
  - 主动提示自身持久化知识
  - 定位"越用越懂你的数字员工"；28.4k⭐（4 月口径）
- 细分变体：NanoClaw（树莓派极简）、NVIDIA NemoClaw（安全增强，官方教程）、TrustClaw/ZeroClaw 等

### 路线 B：开发者侧编排 OS（DeepSeek Harness，10 月 v1.2）

- 定位从插件跃迁为"智能体操作系统"（CSDN 解析口径）：
  - **Codex 与 Claude Code 作为子智能体**进入官方插件列表——编排层收编编码代理
  - Git 工作树支持（并行任务隔离）
  - "思考翻译"能力（思考过程跨模型转译）
  - Cordis 插件化架构、四层解耦
- 中文社区解析密集（10-14~10-22 多篇），官方仓库待锁定跟进
- 意义：载体从"个人助手"扩展到"开发工作流的常驻编排层"

### 路线 C：平台派常驻智能体（OpenAI dots）

- DevDay 2026-09-29 发布：每个 dot 独立云电脑 + 浏览器、4000+ 应用连接、GPT-6 Astra 驱动、关机后继续执行
- 已出 system card；闭源、平台内闭环——与开源路线 A/B 形成生态对峙
- 与 Claude Cowork、Manus 同属平台/产品派

## 三、机制层现状：学习循环的三种实现深度

| 深度 | 实现 | 机制 | 成熟度 |
|---|---|---|---|
| 1. 技能沉淀 | Hermes 学习循环、CoEvoSkills | 复盘→提取技能→持久化→复用；技能包协同进化 | **已产品化**（Hermes 内置） |
| 2. 模式工程化 | self-evolving-agent-patterns | 1000+ 自主循环沉淀为可复用工程模式 | 社区资产，供架构参考 |
| 3. harness 自我改写 | EvolveNet（arXiv 2608.04968）、Raven（EverMind） | 多智能体协作进化各自 harness（调用/工具/验证程序）；Raven 自称 L3 数字生命（**通稿口径，待实测验证**） | 研究期 |

学术基线：2026-06 系统性 survey《From Model-Centric to Environment-Driven Co-Evolution》给出分类框架；2026 内方向从"模型自我改进"（需权重访问）明确转向"环境/外围驱动进化"（API 时代可行）。

## 四、安全与治理（基线）

- 常驻性放大权限风险：Meta Muse 读取本地私信 → 苹果收紧 macOS 完全磁盘访问（系统厂商首次为 AI 代理调整权限）
- "代理攻击面"新命题：代理的身份认证、行为审计、权限分级（Oracle 等报告）
- 自我进化特有风险：技能库被污染/技能漂移、L3 级自主行为的可解释与回滚——目前无标准，空白区
- 工程标配建议（沿全景扫描结论）：最小权限 + 决策日志 + 行为审计 + 技能库版本化

## 五、与相邻课题的交叉

- **决策模型（Jev 跟踪）**：决策层天然适合做 harness 内高频门控（路由/校验/护栏），RLCD²"决策前简短推理"与 harness 进化同构——关注决策层进入 Hermes/DS Harness 类框架的案例
- **Claude Code 生态**：skills/hooks 是"技能沉淀"的平台化实现，若长出学习循环即成为路线 C 的 Anthropic 答案
- **世界模型（Genie 4）**：潜在的自进化训练场（在模拟环境中试错技能）
