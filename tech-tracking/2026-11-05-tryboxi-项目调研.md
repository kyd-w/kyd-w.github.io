## 1. 一句话定位

**"E2B，但在你自己电脑上"**：给 Cursor / Claude Code / Codex / 自研 harness 提供一次性 Linux microVM（Ubuntu 24.04 + 独立内核），agent 在里面跑测试/装依赖/起服务/执行不可信代码，代码不出本机、$0。主体纯 Go（GitHub language: Go，四个二进制全 Go；官网 Next.js），MIT，作者 Karthik Ponna（印度，AI 工程师，个人项目）。

## 2. 核心定性

**"Go 的 AI agent 沙箱"完全成立**——不是蹭概念：host daemon、guest PID 1 agent、MCP 适配器、CLI 四件套全 Go，自建 vsock gRPC 通道、gVisor 用户态网络栈、SQLite+sqlc、OTel 全套。

**定位是"本地 microVM 沙箱"这一层的最新样本**：E2B（云）→ K8s（kubernetes-sigs/agent-sandbox）→ Docker（strands-agents/box）→ 本地 microVM（tryboxi、microsandbox）。差异化全在"安全边界设计"而非"能跑 VM"。

机制拆解（五件套）：

```
1. sandboxd 守护进程   host 侧大脑：HTTP API（unix socket，可选 TCP+token）、
                      vCPU/内存调度账本、VM 驱动、快照、工作区同步、出网策略
2. sandbox-agent      每个 VM 的 PID 1（静态 Go 二进制，initramfs 投递），
                      gRPC over vsock：exec/PTY/超时/文件读写/输出 spool
3. VM 后端双驱动      macOS = Virtualization.framework；Linux = Firecracker+netns
   （网络双栈）        macOS 出网走 gVisor 用户态 netstack，Linux 走 netns+nftables
4. sandbox-mcp        MCP stdio 适配器：11 个 sandbox_* 工具；且 mcp install
                      同时写入 agent 规则（Cursor rules / Claude skill / AGENTS.md），
                      教 agent"何时该进沙箱"而不只是"怎么进"
5. 工作区单向闸门     repo 只进不出：host→VM 增量同步；改动仅经 diff/apply/pull
                      回流，全程备份可 undo；无 virtio-fs 共享目录，文件只走 vsock 拷贝
```

**最有教学价值的两处设计**：

- **密钥永不入 VM**：VM 内只见占位符；出网代理（本地 CA 终止 TLS）仅在允许的 host 上换成真值，回显值会被清洗，占位符发往别处直接拦截；git 代理只对允许的仓库注入 token、拒绝向允许分支之外 push。含密钥的命令/env/stdin/文件在源头就被拒。
- **出网默认白名单**（包 registry、GitHub、Ubuntu 镜像），loopback/LAN/链路本地/元数据地址/CGNAT 永久封禁 + DNS 应答校验；agent 可经 `sandbox_network` 工具"申请放行某 host"——人批准。

## 3. 架构观察

- **性能工程认真**（M4 16GB 实测）：热池取沙箱 20–50ms、金快照建 0.5–0.6s、暂停恢复 0.5–0.7s、fork ~0.8s、冷启到 agent 就绪 1.2s、exec 往返毫秒级——这是"把 microVM 当函数调用"的工程投入
- **数据安全护栏写进代码**而非文档承诺：`safefs.RemoveUnder` 围栏删除、apply/pull 拒绝绝对路径/`..`/逃逸符号链接/`.git/`、3-way merge 用临时文件跑 `git merge-file` 从不碰 index、默认不同步 `.env*`/`*.pem`/`id_*` 等
- **可观测性全套**：Prometheus + OTel trace（`sandboxctl trace` 出逐阶段瀑布图）+ Grafana dashboard 随仓附带
- 上手路径即源码构建（`make images` 约 3 分钟 Docker 内构建 rootfs + `make build`），未见预编译发布物；运行时免 root、免 Docker、免 Lima

## 6. 与投石的关联（克制三条）

1. **威胁模型抄作业**：若 AgentInfra 线走到"agent 执行面隔离"方案阶段，本 README 的 Data safety 一节（单向同步、围栏删除、密钥不入 VM、白名单出网、ask-to-allow）就是现成的需求 checklist，MIT 无引用负担
2. **"MCP + 规则同装"模式**：`mcp install` 同时写 `.cursor/rules` / `.claude/skills` / `AGENTS.md` 教 agent 何时用沙箱——工具分发带行为约定的做法值得进自家 agent 产品设计笔记
3. **范式信号**（与 AgentRQ 调研同框）：agent 中间件分层继续细化——AgentRQ 管"人机断点"，tryboxi 管"执行边界"；两者都以 MCP 为默认协议、都赌"agent 数量与不可信代码执行量同涨"
