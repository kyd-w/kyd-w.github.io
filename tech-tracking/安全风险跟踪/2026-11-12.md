# 安全风险快照 · 2026-11-12

> 建档首篇。素材：Go 生态一日 14 个安全公告（2026-10-25/26 发布，经公众号 PFinalClub 11-03 中文首发、本文核实补全 CVE）。

## 事件：Go 生态底层库一日 14 公告

2026-10-25/26，NVD 与 GitHub Advisory Database 集中发布 14 个 Go 生态安全公告，全部落在三个"没人直接写、但人人间接用"的底层库上。

| 库 | CVE | 漏洞 | 危害 | 修复版本 |
|---|---|---|---|---|
| **rclone** | CVE-2026-116189（GHSA-mhj4-h9x6-3888） | `selfupdate` 信任 PGP-clearsigned SHA256SUMS 块**之前的未签名字节**，签名校验被架空 | **供应链级**（最重）：镜像被黑/MITM → 自更新装投毒二进制；影响 1.55.0 ≤ v < 1.75.2 | v1.75.2（2026-10-09） |
| **klauspost/compress** | CVE-2026-116591（GHSA-fpmh-frq8-7rj8 / GO-2026-6865，CVSS ~8.7） | zstd 双块帧（~27KB）令 FSE 解码复用脏状态，整数溢出（CWE-190）→ 越界 panic | 接收外部压缩数据的服务一条请求即 DoS（DecodeAll 与流式解码均中招） | v1.20.2 |
| **go-jose** | CVE-2026-116587（GHSA-mgcc-cww5-fp2q） | JWK 中 RSA 模数/素数无上界校验，超大密钥耗 CPU | 解析不可信 JWK 即 DoS | v4.1.6 |
| **go-jose** | CVE-2026-116586（GHSA-vvm8-gf78-28g4） | 深层嵌套 JSON 耗尽 Go 栈 | 解析不可信 JWT/JWKS 即栈溢出崩溃 | v4.1.5 |

关联背景：

- klauspost/compress 是 2026 年第二次中招（7 月 GO-2026-5841，同为 crafted input）——底层压缩库成为持续攻击靶
- 同批次还有 CVE-2026-116589 等（corgea 批次分析）
- 另发现同类但更重的独立事件：**CVE-2026-88018**（CVSS 9.8，rclone `serve s3 --auth-proxy` 认证绕过）——跑 rclone 服务端的场景风险高于本次 selfupdate 漏洞

## 与本课题框架的对应（为什么用它立项）

1. **冲击层侧写**：14 个公告一天落地，下游修复窗口被压缩——这正是"AI 加速披露/利用周期"下的常态预演（无论本批是否 AI 参与，防御节奏问题同构）
2. **新增面实证**：rclone selfupdate 漏洞打击的是**自更新机制本身的信任基础**——与自我进化智能体课题的核心机制（自动进化/自动装载技能）直接同构：进化越自动化，供应链信任越尖锐
3. **波及面与 agent 生态重叠**：rclone 是服务器/agent 数据搬运标配；klauspost/compress 是 Go microvm 生态标配（tryboxi 一类项目大概率间接依赖）
4. 底层库漏洞的共性：**接受不可信输入**（外部压缩数据、不可信 JWK/JWT、更新源）时缺上界校验/信任边界——AI 生态里这三类输入恰好都是 agent 暴露面

## 行动（已核实的修复基线）
