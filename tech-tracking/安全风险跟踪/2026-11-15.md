## 🚨 变化：Claude Code「Don't Ask Again」致 1,122 个公开文件泄露凭据（已核实，多批次）

- **机制**：用户点"Don't ask again"后，含内联密码/API key/token 的完整命令被写入 `.claude/settings.local.json`，该文件随仓库提交推上公开 GitHub——**CLI agent 权限持久化配置 × Git 工作流的组合缺陷**，非模型漏洞
- **规模**（Apiiro 研究）：1,122 个公开文件 / **2,539 个真实凭据** / 1,994 个公开仓库
- **证据级别**：厂商研究（Apiiro）+ The Hacker News 等多家覆盖；W45、W46 两批次出现（多批次=非一次性噪音）
- **对本课题的意义**：维度 3 从"MCP 越权散案"升级到**主流 coding agent 自身默认行为致泄密的大规模实案**——agent 生态的"便利性配置"直接生产凭据泄露，命中立项框架"新增面"层的典型样本；与 11-14 维度 3 的 MCP 权限滥用群共同构成实案带
- **本机行动（已完成，11-15）**：检查发现本仓 `.claude/settings.local.json` **正中此模式**——第 45 行允许命令里存有明文 DeepSeek API key（当时给 Pi 配环境时的命令被"Don't ask again"存档）。核实：该文件从未进 git（`git log --all` 无记录），已补 `.gitignore` 覆盖 `.claude/`，**未发生泄漏**；该 key 建议择机轮换（明文存于本机配置 + Pi 端 env 文件）。教训入档：给 CLI 传命令时永远不内联凭据，一律走环境变量文件
