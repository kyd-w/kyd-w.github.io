## 1. 前沿模型：10 月主线是"效率战"而非"智力战"

**Anthropic 与 OpenAI 在 10-07 同日重建产品线**（[shattered.io 综述](https://shattered.io/what-changed-in-october-2026-two-new-model-families-one-week-apart)，10-20）：

| 层级 | Anthropic | OpenAI | 备注 |
|---|---|---|---|
| 便宜主力 | **Haiku 5.5**（10-07）：$0.10/$0.50，1M ctx，>100k token 价格 ×5；batch 再减半 | **GPT-6 Luna**：$0.10/$0.50（同价！），1.05M ctx，>272k 涨价 | 底价精确对齐=价格战标志 |
| 中档 | Opus 5.5（9-22）：$4/$20 | GPT-6.1 Sol：~$2/$10（第三方口径，官方未确认） | |
| 旗舰推理 | Fable 5.1：$10/$50 | GPT-6 Astra：API 价未公布 | 长程 agentic 定位 |

- **关键分化**：同价位下 Haiku 5.5 在 agentic/工具调用基准大幅领先（OSWorld 2.1：72.4% vs 48.9%；Terminal-Bench 4.0：39.2% vs 16.4%），但通用编码差距小（FrontierCode 46.4% vs 42.4%）——**"便宜模型干 agentic 活"是 Anthropic 本轮主打**
- 消费侧：OpenAI Pro 拉出 $100/$200/$500 三档（Pro 500 含 Ultrafast 变体）；两家免费档与 $20 档持平
- Google：Gemini 4 Argon 10-13 GA（$2/$10 介绍价，12-01 翻倍）；**Gemini 4 Carbon**（10-28）Agent 模型
- 国产：DeepSeek V4.1 Flash Cyber、Kimi K3.1 Pro Highspeed、Nemotron 3.5 Transcribe、Particle-1 等均在 10 月发布（[LLM Gateway 时间线](https://llmgateway.io/timeline) 共 22 个）

## 2. 常驻智能体：OpenAI dots

- DevDay（09-29）发布，ChatGPT 内集成：每个 dot 有**独立云电脑 + 浏览器**，与本机隔离；GPT-6 Astra 驱动；4000+ 应用连接；合上笔记本后继续后台执行
- 意义：Agent 形态从"对话中调用"变为"7×24 常驻Worker"。与决策模型（毫秒级高频决策）互补——一个解决"常驻"，一个解决"廉价高频判断"
- 已出 [system card](https://academy.codearia.com/en/articles/openai-dots-always-on-agent-system-card)，安全边界是后续看点

## 3. 自我进化智能体：进化 harness，而非进化模型

- **Raven**（EverMind，开源，[USA Today 通稿](https://www.usatoday.com/press-release/story/37979/evermind-launches-raven-agent-the-self-improving-harness-that-defines-l3-level-digital-life)）：自我改进 harness，自称"L3 级数字生命"，终端直装、可自托管
- **EvolveNet**（[arXiv 2608.04968](https://www.alphaxiv.org/abs/2608.04968)，10-11）：多智能体协作进化各自 harness（模型调用、工具使用、验证逻辑所在的执行程序）
- 社区资源：self-evolving-agent-patterns（1000+ 自主循环的工程模式）、CoEvoSkills（技能包协同进化）
- 判断：**不碰权重、只进化外围脚手架**，是自我进化在 API 模型时代唯一可落地的路线——与 Claude Code 的 skills/hooks 生态方向一致，值得作为独立课题跟踪

## 4. 世界模型：Genie 4（DeepMind，10-27）

- 文本 prompt → 实时可交互、可走进去的世界；原生多模态（环境音/音乐/对话角色）；物理改进；连续运行时长翻倍至 ~2 分钟；支持实时转向控制
- 定位：游戏、模拟、具身智能训练环境的统一前沿。国内侧对应信号：济南 AI 产业大会（10-14~16）聚焦具身智能
- 待观察：与决策模型结合（在世界模拟里跑决策层训练）是否成为 2027 具身方向的标准做法

## 5. 开源个人助手与端侧 AI

- **OpenClaw**：GitHub 史上最快增长项目——60 天打破 React 十年星标纪录（3 月），8 月 ~388k⭐/81k forks/80k commits（[GitHub 官方博客](https://github.blog/open-source/maintainers/openclaw-went-viral-meet-the-maintainers-building-and-securing-it)）。本地运行的个人 AI 助手，通过 Discord/iMessage/Slack/Teams/Telegram 等既有渠道交互；维护成本问题（创建者月贴 ~$20k）也是开源可持续性样本
- **Meta Muse Gadgets**：开源固件 + Linux SDK，把 Muse 助手移植到树莓派/ESP32，官方给墨水屏助手、HDMI 电视棒等参考设计——AI 硬件开发门槛大幅下沉
- 配套语言/工具：Swift 6.4（Wasm 生成提速至 40x）；Liquid d1-omni-600M（文/图/音决策模型跑边缘设备，见 Jev 跟踪）
- 趋势判断：**"AI 从云端向端侧、硬件侧下沉"** 是 9-10 月最一致的产业方向（CSDN 盘点同结论）

## 6. AI 安全：从讨论进入系统级管控

- 事件链：记者发现 Meta Muse 代理读取本地私信 → **苹果收紧 macOS"完全磁盘访问"**（首次为 AI 代理调整系统权限体系）→ Oracle 等报告提出"代理攻击面"（代理的身份认证、行为审计、权限分级）
- 决策模型侧同样有对应（对抗操纵 typed 输出无可见异常，见 Jev 快照维度 6）
- 判断：AI 代理安全是确定性增量方向，会催生新安全产品线与岗位；与我们做 Agent 应用直接相关——**最小权限 + 决策日志 + 行为审计**应作为内部 Agent 开发标配

## 7. Agent 框架与工具链：收敛期

- **Microsoft Agent Framework 1.0** GA（.NET/Python，合并 Semantic Kernel + AutoGen），企业侧主要竞争者
- 格局稳定：LangGraph（复杂有状态工作流）、CrewAI、Google ADK、OpenAI Agents SDK、LlamaIndex Workflows；社区共识是"没有唯一最佳，按场景选"
- **Spring AI 里程碑版**：Java 体系原生 AI 集成落地（对国内企业 Java 存量系统是重要信号）
- **Cursor Continuity**：S3 WAL 架构优化 Git 存储，300+ pushes/s——AI 高频小批量提交正在倒逼代码协作基础设施重构；CodeScene 案例：AI 代理 3 周重构 30 万行 C 代码、token 成本 ~$4000、沉淀可复用操作手册
- JetBrains Mellum 2.1（12B MoE 开源编程模型）延续垂直编码模型路线

## 8. 算力与前沿基建（背景板）

- 台积电洽谈参与 SpaceX/特斯拉 **Terafab**：得州最多 6 座晶圆厂、单座投资至 $200 亿，服务 AI 芯片需求——短期算力紧缺格局不变
- 深圳 **Entropec 量子计算算力平台**：经典超算 + 张量网络模拟千比特量子系统，10 月商用——"模拟量子"的务实路线

## 跟踪建议（优先级排序）

1. **建议立项**：① 自我进化智能体（harness 进化，与 Claude Code 生态直接相关）② 常驻智能体（dots 的 system card 与生态开放情况）——两者都是"决策模型"之外最有范式潜力的方向
2. **保持关注**：世界模型（Genie 4 → 具身训练环境）；AI 代理安全（系统级管控是增量确定性最高的方向）
3. **工程侧可行动**：Haiku 5.5 同价位 agentic 领先 + batch 减半，子代理/分类/压缩类负载值得切换评估；注意 100k token 价格悬崖需加护栏
4. **国内窗口**：Spring AI 对 Java 存量企业的 AI 化改造是务实路径；国产三强（DeepSeek/Qwen/Kimi）在企业级成本敏感场景的替代价值持续上升
