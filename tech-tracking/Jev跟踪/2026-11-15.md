## 🚨 Google 首个决策模型上线：Gemini Decisions API（官方已核实）

[Gemini Decision 1](https://aistudio.google.com/docs/models/gemini-decision-1) + [Decisions API](https://aistudio.google.com/docs/decisions-api)，[官方公告](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api)（blog.google）：

| 指标 | 官方口径 |
|---|---|
| 定价 | **$0.10 / 1M 输入 token，输出 $0**（不生成文本） |
| 延迟 | 150–250 ms 端到端 |
| 吞吐 | 单次调用最多 **1,000 个 typed 问题** |
| 输入 | 多模态：音频/视频/PDF |
| 输出 | 校准置信度分数（probabilities） |
| 官方对比 | 号称比 Gemini 3.5 Flash-Lite 便宜 ~5x（决策型负载共享基准套件） |
| 分发 | 已上 [OpenRouter](https://openrouter.ai/google/gemini-decision-1)（google/gemini-decision-1）+ LangChain 集成 |

**判断**：

- 定价与 OpenAI Decisions API（10-06 公测 $0.10/M）持平，但加了**输出 0 计费**与**多模态输入**两个新维度——价格战从"输入单价"打到"计费结构"
- OpenAI（10-06）、Microsoft（Decision-1）、Google（本周）三家全部亲自下场后，"大厂入场"叙事对 Jev 定价/护城河的冲击进入实测段：**下期 OpenRouter 份额榜（11-14 榜单无此行）将给出 Google 入场首周的需求侧答案**
