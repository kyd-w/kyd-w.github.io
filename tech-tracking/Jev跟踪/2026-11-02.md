1. **"决策模型"正式成为品类**：一个月内 OpenAI、Microsoft、AWS、Cloudflare、Snowflake、Perplexity、Liquid AI 全部入场。市场弃用 TypeSafe 的 "System One model" 命名，通用名定为 **decision model**；TypeSafe 的请求 schema 成为事实标准（类比 Chat Completions API 之于 LLM）
2. **TypeSafe 融资 $870M A轮，估值 $7.5B**（10-09，a16z 领投，与微软 Decision-1 发布同日）；宣称发布数日内用户破 100 万、约 1/3 财富 500 强在用（未点名客户，待证实）
3. **RLCD 论文落地**：此前"仅官方口径无论文"的状态结束——arXiv 2609.29429《Just Ask Jev: RLCD》+ 开源实现 OpenJev-RLCD（2609.38850）+ 后继 RLCD²（2610.17309）
4. **Jev 1.14 预览版**（10-14）：图像输入、bounding box 答案、262k 上下文——上次快照关注的"多模态落地"已兑现（仍为 opt-in、非生产可用）
5. **中国信号**：国产大厂整体观望（腾讯云文章称"理性选择"），但开源侧 **StartLux-Decision**（9-30 发布，v1.1 于 10 月中旬）在 HF Decision Index 开源榜登顶，自称多项基准超 Jev（厂商口径，待独立验证）

## 二、七个跟踪维度现状

### 1. Jev 本体

- 版本：Jev 1.14 预览（10-14）——图像输入 + bounding box + 262k 上下文，均 opt-in
- 定价：维持 $0.042/M 输入、输出免费；微软已"按分对齐"，OpenAI 反而贵 2.4x（$0.10/M）
- 采用：Vercel 数据——两周内 35% 付费 AI Gateway 团队采用（平台上最快，此前 13% 的口径被上调取代）；OpenRouter 按 routed requests 排名初期 Jev 第一
- 融资：$870M @ $7.5B；"100 万用户 / 1/3 财富 500 强"为公司自称，待证实
- 下次关注：Jev 1.14 GA；是否出官方自托管/私有化；OpenRouter 榜单份额变化

### 2. 训练方法（RLCD）

- **arXiv 2609.29429**《Just Ask Jev: Reinforcement Learning for Calibrated Decisions》（R. Guo et al.）——RLCD 正式成文：一次输入多 typed 问题、奖励与校准挂钩
- **arXiv 2609.38850**《OpenJev-RLCD》——社区可跑的 RLCD 实现（采样答案、奖励绑定校准）
- **arXiv 2610.17309**《AutoThink》——提出 **RLCD²**（Calibrated *Deliberative* Decisions），决策前允许简短推理（与 PostHog Jeeves、OpenAI LLM-套壳路线呼应）
- 下次关注：RLCD 与开源管线（kev/NanoJev）实测校准差距；RLCD² 是否成为"难例慢通道"的标准解法

### 3. Laya 专项（Convai Innovations）

- 无新权重/大版本，迭代集中在运行时：0.3.11（9-23，加载快 10x）→ 0.3.13（9-24，TileLang GPU fast path，`fast=True` 精度对齐 bf16）→ **0.3.14（10-08，新文档站）**
- 0.3.7 起：`laya-serve` **Jev 兼容**、多检查点路由（100+ 语言按请求选 checkpoint）、官方文档标注 label bias 限制（见维度 6）
- 生态位变化：Laya 从"唯一开源对标"变成"开源第一梯队之一"（Clef/Decider/pplx-decider/StartLux 均入场）； receptron/laya 定位为 Jev 兼容运行时
- 下次关注：是否跟进多模态（竞品 Clef-omni/d1-omni 已出）；昇腾路线进展；版本号 0.3.x → 0.4/1.0 信号

### 5. 应用范式

- 推理服务器层（vLLM/llama.cpp/Ollaya）+ 数据平台层（Snowflake SQL 函数）+ 边缘层（Cloudflare Workers）+ 工作流层（Airflow/Camunda/Kestra，发布数日内即集成）——决策模型的"四个天然落点"已成型
- Kai Waehner 架构建议（值得沉淀进我们自己的设计）：决策模型放自有接口后面、记录决策日志（state/question/answer/probabilities/version）、阈值留在工作流不在模型、每个版本重新校准
- 下次关注：主流 Agent 框架（LangChain 已接入）是否把"决策层"做成一等公民；国内工作流/低代码平台集成

### 6. 学术与批评

- **label-flip 批评**（option-name bias 的升级版实证）：交换 yes/no 标签语义后准确率崩塌——模型跟随标签字面而非语义，已在 Laya 官方文档中作为已知限制标注
- **首个对抗性基准**：typed 输出永远"格式正确"，被操纵时无可见异常——攻击比 LLM 更难察觉
- 共性弱点（多项独立评测一致）：**数字、日期、序数刻度**；校准跨模型差异大，常需在自己数据上做温度拟合
- 各家"第一"并存：Liquid/Perplexity/Snowflake/Cloudflare 各自在自选子集上第一（Index 换版本、子集不同、全为厂商自跑）——**独立评测仍然缺位**
- 下次关注：HF Jev Decision Index 的 private test 占比机制（60% 私有同技能题 + 40% 私有任务，v0.4.1）能否压制刷榜

### 7. 产业信号

- **基准设施**：HF《Jev Decision Index》（multimodalart，v0.4.1，~61 模型）+ 独立 JevBench（Benchmark Heaven：准确率/校准/延迟/成本）+ OpenRouter 实际流量榜——三层观测就位
- **国内**：大厂按兵不动（腾讯云文章：TDM 门槛低、难撑独立品类、不涉 AGI 突破、头部已有成熟决策系统——"暂缓是理性选择"）；开源侧 StartLux/InternLM Intern-Decision 活跃；Qwen3.5 成为全球决策模型事实基座（采购合规注意 lineage）
- **商品化速度**：类别"出生即商品化"——4 周内定价被超大规模厂商锚定（$0.042/M），价值向平台（数据旁路推理）、工具链（评测/微调）、编排层（阈值+决策日志）转移
- 下次关注：国内大厂是否在 2027 Q1 前入场；Decision Index 是否出现公认的独立排名

## 四、跟踪建议（下一步）

1. **盯 Jev 1.14 GA 与 OpenRouter 份额**：Jev 从"唯一"变"第一"，流量份额是护城河的硬指标
2. **盯 Decision Index / JevBench 的独立化进程**：现在所有"第一"都是厂商自跑，谁先出可信独立榜谁定义品类
3. **Laya 关注点转向多模态与版本号**：纯文本决策已商品化，Laya 若停在 0.3.x 文本单模态有掉队风险
4. **国内窗口期**：大厂观望 + StartLux 登开源榜——若 2027 Q1 国内大厂入场，大概率走"平台内嵌"（钉钉/飞书/企微工作流里的决策函数）而非独立 API
5. **工程侧可启动**：决策接口已标准化且可替换——自建评测集 + 决策日志 + 阈值外置的架构模式可以先行落地，模型层保持可切换
