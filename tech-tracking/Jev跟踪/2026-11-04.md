## 实测二：中英问题对照实验（同内容、同选项语义）

6 条中文 + 4 条中英对照，关键结果：

| 输入 | 中文问题 | 英文问题 | 真值 |
|---|---|---|---|
| Jev 1.14 GA 图像输入（中/英） | 待定 0.47 | 相关 0.69 ✓ | 相关 |
| DS Harness v0.3 插件化 | 无关 0.61 ✗ | 相关 0.78 ✓ | 相关 |
| Win11 26H2 推送 | 待定 0.97 | **相关 0.80 ✗** | 无关 |
| 美股收涨 | 无关 0.87 ✓ | **相关 0.63 ✗** | 无关 |

**结论：零样本存在两种系统性偏置，语言不同错误模式不同**——

- 中文问题：保守漂移，几乎全糊"待定"（漏报型，"待定"标签充当安全岛）
- 英文问题：字面偏置，输入带 "tech/news" 字样即判相关（误报型）
- 与官方已知的 label bias / label-flip 限制一致（见 README 维度 6）；此前记录的"typed-decisions 零样本全均匀"属同类症状

**判定**：症状是"判定边界"问题而非"知识"问题 → 轻量校准可解，不必全量训练。阶梯：①选项/问题措辞工程（"待定"措辞是保守漂移的放大器）→ ②LoRA 校准微调（数百~数千条标注即可，单卡 4–6GB / Colab T4 够用）→ ③RLCD 全量（暂不需要）。

## 延迟（Pi 4B CPU）

冷启动 ~25s（模型加载），热启动 **~2s/条**。批量影子场景够用；交互式决策服务建议 laya.cpp（近实时、Jev 兼容端点）。

## 分场景训练的证据

官方 laya.cpp 三个 checkpoint（english / multilingual / typed-decisions）= **按任务分训发布**——分场景校准有效且是官方自身做法。工程形态推荐：一个基座 + N 个 LoRA adapter（几 MB 热切换）；本课题三课题高交叉，先 multi-task 单 adapter，数据攒厚再拆。
