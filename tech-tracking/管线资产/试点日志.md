## 校准记录 · W46 dry-run（2026-11-17）

**方法**：本机模拟沙箱，输入严格限公开面（W46 周报 + README@11-14 版本 + 11-14 快照 + `_topics.yaml` + playbook/rubric），产出草稿-W46（[weekly-draft 分支](https://github.com/kyd-w/kyd-w.github.io/tree/weekly-draft/tech-tracking/自我进化智能体跟踪)），与人工 11-15 快照逐项 diff。校验对象是**判断资产的充分性**，非模型能力（操作者见过人工快照，存在答案泄漏，能力结论不作数）。

**逐项对照**：

| 维度 | 人工 11-15 | sandbox 草稿 | 判定 |
|---|---|---|---|
| 事实覆盖 | 5 行 | 6 行（拆分更细） | ✅ 集合一致，无漏无多 |
| 🚨 判定 | 无 | 无（提议权也没用） | ✅ 一致 |
| 判断·第4代/平台吞并 | 三案例强化、偏向平台吞并、换代史不加行 | 同 | ✅ 达成 |
| 判断·1.21x 立尺 | 首个可量化基准，此后对照通稿 | 同 | ✅ 达成 |
| 判断·Famou 定性 | 国内大厂首次平台级产品名 | 同（从周报 #13 推出） | ✅ 达成 |
| 判断·标准化前奏 | 引用"11-08 判定继续验证中"（跨快照链记忆） | 只能挂 README watch，无历史出处 | ⚠️ GAP-2 |
| GenericAgent/EvoGroup 状态 | "W45 已录，第三次顺延" | 视为全新条目（11-14 基线里没有） | ❌ GAP-1 |

| 交叉段 | 引同日 Jev 快照 + Agent范式 README 日志 | 只能引周报条目 | ℹ️ 增强 NOTE-A |

**GAP-1（结构性）：挂起动作断链**——挂起状态只存在于快照链历史（11-08 挂起、11-14 未处理），以"上次快照"为唯一基线的 agent 数不出顺延计数。**修复**：spec 输入 3 改为"快照链（最新一份为增量基线，回溯全链核对挂起顺延计数）"——快照链全公开，回溯即可数出，无需新载体文件。
**GAP-2（同因）：跨快照判断线索丢失**——"散点密度是标准化前奏"是 11-08 的判断语言，不在 README 也不在上次快照。同 GAP-1 修复（允许回溯快照链）。
**NOTE-A（增强，非缺口）**：spec 允许引用其他课题最新快照作交叉（部署时点上周日人工/agent 蒸馏已存在）。

**结论**：判断资产充分性 = 事实路由/增量判定/框架挂靠/口径分级全部可由资产支撑达成；两个缺口同源（输入面太窄），已回补 spec + playbook。W47 起真部署可期；首期人工合入流程以本 dry-run 的 weekly-draft 分支演练。
